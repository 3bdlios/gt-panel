# Repair format — engine 2

الكتالوج JSON يحتوي schema=2 وitems. الحزمة tar.gz بملفات عادية فقط؛ لا إدخالات مجلدات أو روابط. المسارات داخل الأرشيف نسبية دون ./، بينما files وtargets تحوي المسارات النهائية المطلقة. كل عنصر يحدد:

- id، title، description، category، version، url، sha256، size.
- action="repair" وmin_engine=2.
- compatibility: قوائم model وimage وversion وpython؛ مطابقة صريحة بلا wildcard.
- files: قائمة الملفات النهائية.
- targets: لكل ملف sha256 للمحتوى الجديد، before لقائمة بصمات الملفات القديمة المقبولة، أو null إذا كان الملف غير موجود، وmode بقيمة 420 (0644) أو493 (0755).
- checks: فحوص قراءة فقط. sha256 يحوي path وbytes وsha256؛ uboot_env يحوي path وbytes وdata_offset=4 أو5 وbyteorder وvalues المطلوبة.
- warning: أثر التثبيت وأي تأثير لاحق عند تشغيل الملفات.

راجع repository/gtcombo-android.spec.json للمثال الكامل. ثبّت البصمات بعد مراجعة الملف، ولا تعتمد اسماً أو موديل dreamone لإثبات عتاد GT MEDIA COMBO.

## إنشاء الأرشيف

ضع الملفات تحت directory يحاكي مسارات الرسيفر، مثلاً payload/usr/lib/gtcombo/example.py. جهز وصف spec.json وفيه targets والبصمات. ثم:

```sh
python3 tools/pack_repair.py spec.json payload/ repository/example-v1.tar.gz
```

ينتج الأرشيف وexample-v1.tar.gz.item.json. يضيف بيانات الحجم والبصمة وجرد الملفات؛ ضع url النهائي في الوصف قبل البناء. أضف العنصر الناتج إلى items في manifest-v2.json، وارفع الملفات جميعاً إلى المستودع. الحزم المنشورة ذات النسخة الواحدة لا تُستبدل بمحتوى مختلف؛ استخدم اسماً وإصداراً جديدين.

## السياسة المحلية

المسارات المعتادة للبلجنات والسكنات تظل متاحة. إصلاحات النظام لها جذور افتراضية إضافية:

- /usr/lib/gtcombo/
- /etc/init.d/
- /usr/lib/enigma2/python/Components/
- /usr/lib/enigma2/python/Screens/

يمكن لمسؤول الصورة توسيع هذه السياسة محلياً، دون تحديث كود GT Panel، عبر /etc/gt-panel/policy.json:

```json
{"repair_roots":["/usr/lib/gtcombo/","/etc/init.d/","/usr/lib/enigma2/python/Components/","/usr/lib/enigma2/python/Screens/","/etc/enigma2/"]}
```

هذا الملف يجهزه المسؤول محلياً ولا يقبل استبداله من الكتالوج. المسارات الجديدة تحت /etc أو/usr فقط، ولا يسمح بكتابة /dev أو/proc أو/sys أو/flash من محرك الحزم. ملفات GT Panel وسياسة التثبيت وملفات الحسابات الحساسة محمية. اختيار جذور أوسع يمنح المستودع قدرة على استبدال ملفات أكثر بعد تأكيد التثبيت؛ لا تضف جذوراً عامة دون مراجعة.

لا توجد خطوات shell أو postinstall مخفية. الفحص يقرأ البيانات ولا ينفذ الكود القادم من الحزمة. الملفات التنفيذية التي تثبتها الحزمة قد تعمل لاحقاً عند استخدام الميزات أو الإقلاع، ويجب توضيح ذلك في warning.

## اختبار قبول قبل النشر

على نسخة USB قابلة للاستعادة: جرّب رفض موديل/بصمة محمل مختلفة، ورفض ملف محلي معدّل، وإلغاء شاشة التنزيل وشاشة التثبيت، ثم تثبيت الحزمة واسترجاعها. لإصلاح أندرويد اختبر كلاً من قائمة الطاقة وقائمة الإقلاع، وبقاء الفلاش موصولاً، وعودة العلم إلى0 بعد نجاح التحويل. سجل النتائج وحدودها في وصف الإصدار.
