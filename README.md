# GT Panel 1.0.1

بلجن Enigma2 لمشروع GT MEDIA COMBO، بأقسام Fixes وPlugins وSkins وUpdates. حزم Python 3 فقط؛ لا تفترض أن هوية الجهاز Dreambox One لأن الصورة مشتقة منه. لا يجري اتصالاً عند إقلاع النظام؛ يطلب manifest مرة عند فتح البلجن. لا توجد مهام دورية أو إعادة محاولة تلقائية. تنزيل الحزمة يحدث فقط عند طلب المستخدم، وتثبيتها يحتاج تأكيداً ثانياً بعد التحقق. لا إعادة تشغيل تلقائية.

## حالة التسليم

تم بناء DEB وIPK وفحص المحتويات واختبار منطق الأمان محلياً. لم يتم تثبيت البلجن أو تشغيل واجهته على الرسيفر؛ يلزم اختبار قبول على نسخة USB احتياطية قبل اعتماده. المستودع المرتبط هو 3bdlios/gt-panel؛ الكتالوج في جذر main وحزم الأمثلة تحت repository.

السياق المراجع: مشروع Prepare Enigma2 USB backup يخص GT MEDIA COMBO وإصلاحات العرض والريموت والبث والواي فاي. آخر تعديل لإخفاء نص الإقلاع تم التراجع عنه. لا تتضمن هذه الحزمة تلك الإصلاحات ولا تعدل ملفات النظام أو الإقلاع أو مصادر التحديث الرسمية. لم يثبت في المراجعة اعتماد نسخة نهائية بعد التراجع.

## التثبيت الأولي

1. احتفظ بنسخة USB قابلة للاسترجاع. على الرسيفر افحص Python ومدير الحزم؛ استخدم الصيغة التي يدعمها النظام فعلاً.
2. انسخ الحزمة المناسبة إلى /tmp. أوامر التثبيت التالية تغيّر النظام؛ تنفذها أنت عندما تقرر التثبيت:

```sh
python3 --version
command -v opkg
command -v dpkg
# اختر أمراً واحداً فقط حسب مدير الحزم الموجود:
opkg install /tmp/enigma2-plugin-extensions-gtpanel_1.0.1_all.ipk
# أو:
dpkg -i /tmp/enigma2-plugin-extensions-gtpanel_1.0.1_all.deb
```

لا تتجاوز أخطاء الاعتماديات بالقوة. قد تختلف أسماء حزم Python/Twisted بين الصور، وعندها عدّل Depends في tools/build.py وأعد البناء للصورة المستهدفة. الحزمة لا تحتوي postinst أو سكربتات تفعيل ولا تغيّر إعدادات الإقلاع. أعد تشغيل الواجهة يدوياً بعد إكمال الإعداد. افتح GT Panel من قائمة البلجنات.

## تعريف هوية الصورة وربط GitHub

على جهاز تجريبي، يقرأ مسؤول الصورة القيم الحقيقية:

```sh
cat /proc/stb/info/model
python3 -c 'import sys; print("%s.%s" % sys.version_info[:2])'
cat /etc/os-release
```

أنشئ /etc/gt-panel بصلاحية 700، وضع فيه ملفين بصلاحية 600 مملوكين للجذر:

- device.json: انسخ repository/device.json.example، عيّن model بالقيمة الحقيقية، وimage باسم gt-enigma2، وversion بمعرّف إصدار محلي فريد للصورة التي اختبرتها. هذا الملف يجهزه مسؤول الصورة، ولا يقبل البلجن استبداله من GitHub. Python يقرأه البلجن من المفسر نفسه.
- repository.json: انسخ المثال وعدّل YOUR-ACCOUNT/gt-panel في repository وmanifest_url. المستودع عام؛ لا تُضمّن كلمات مرور أو رموز دخول.

الكتالوج manifest.json موجود في جذر فرع main. أرشيفات demo-*.tar.gz موجودة في repository بروابط raw مباشرة. حدّد compatibility بالقيم الدقيقة model/image/version/python بعد اختبار صورة الجهاز. القيم الافتراضية لا تطابق جهازاً حقيقياً عمداً. لا تستخدم wildcard. قيم Python في manifest مثل 3.12 وليست اسم حزمة Python. تبقى أقسام الواجهة متاحة حتى إذا كانت فارغة.

الأمثلة الأربعة تضع ملفات نصية فقط؛ عنصر Updates التجريبي ليس تحديث firmware، وعنصر Fixes ليس إصلاحاً فعلياً. يمكنك حذف الأمثلة واستبدال items بقائمة فارغة حتى تُراجع حزمك.

## صيغة الكتالوج والحزم

راجع repository/manifest.json لمثال كامل. schema=1. لكل عنصر id فريد، category من الأقسام الأربعة، title، description، version، url، sha256، size، files، compatibility. size حجم التنزيل بالبايت؛ sha256 بصمة الأرشيف النهائي، وfiles قائمة مطابقة تماماً لمسارات الملفات النهائية. إصدار العنصر للعرض فقط: لا يطبق البلجن ترتيب ترقيات أو يمنع الرجوع لإصدار أقدم؛ يجب ذكر ذلك في وصف العنصر.

الأرشيف tar.gz يضم ملفات عادية فقط، بأسماء نسبية دون بادئة ./ أو /، ولا يتضمن إدخالات مجلدات أو روابط أو سكربت تثبيت. أنشئ الأرشيف باستخدام tarfile وإضافة الملفات منفردة، كما في tools/make_demo.py. الحد الأقصى 16MiB مضغوط و32MiB بعد الفك، و200 ملف لكل عنصر. لا تُغيّر الأرشيف بعد نشر بصمته.

المسارات المسموحة:

- /usr/lib/enigma2/python/Plugins/Extensions/NAME/... باستثناء GTPanel نفسه.
- /usr/share/enigma2/GT-NAME/... للسكنات المخصصة.

لا يُفعّل السكن تلقائياً. لا يوجد تشغيل shell أو تثبيت DEB/IPK قادم من الكتالوج. ملفات البلجن قد تحتوي كوداً يعمل عند إعادة تشغيل الواجهة؛ لذلك يجب أن يكون المستودع موثوقاً ومراجعاً. HTTPS والبصمة يحميان النقل والمطابقة، لكن manifest ليس موقّعاً بمفتاح مستقل، ولا يحميان من اختراق حساب مالك المستودع. استخدم حماية الفرع والتحقق الثنائي ومراجعة الإصدارات. لإصلاحات ملفات core أو kernel/DTB يلزم تصميم مستقل بمتطلبات توافق واسترجاع أقوى؛ هذه النسخة ترفضها.

## النسخ والاسترجاع

بعد التأكيد، يفحص البلجن المساحة والمسارات، ثم يحفظ الملفات السابقة والأذونات وقائمة الملفات الجديدة تحت /var/lib/gt-panel/TIMESTAMP-... قبل الاستبدال. الزر الأزرق يعرض النسخ؛ OK ثم التأكيد يسترجع الملفات السابقة ويحذف الملفات التي أضافتها العملية. الاسترجاع يكتب فوق أي تعديلات لاحقة في نفس الملفات. لا يحذف البلجن النسخ تلقائياً. هذه نسخ ملفات وليست صورة كاملة للنظام.

الفشل العادي أثناء الكتابة يشغّل التراجع؛ استبدال كل ملف يتم ذرياً. العملية الكاملة ليست ذرية عند انقطاع الكهرباء: قد تبقى بعض الملفات قديمة وبعضها جديدة. عند الانقطاع يمنع install.lock أي عملية جديدة حتى يفحص المسؤول journal.json والنسخة الاحتياطية. بعد التأكد أن لا عملية GT Panel تعمل، احذف القفل ثم اختر النسخة من الواجهة للاسترجاع، أو شغّل التالي من جلسة صيانة بعد تعيين المسار الحقيقي:

```sh
python3 -c 'import sys; sys.path.insert(0,"/usr/lib/enigma2/python/Plugins/Extensions"); from GTPanel.core import restore; restore("/var/lib/gt-panel/REPLACE_WITH_BACKUP_DIRECTORY")'
```

لا تنفذ تثبيتات متزامنة من أدوات أخرى أثناء العملية. عند فشل التراجع احتفظ بمجلد النسخة والسجل، واستخدم نسخة USB للاستعادة. لا يزيل هذا البلجن التحديثات الرسمية ولا يعطل خدماتها.

## بناء واختبار المصدر

```sh
python3 -m unittest discover -s tests -v
python3 tools/build.py
```

يتطلب البناء Python 3 وdpkg-deb وar على الكمبيوتر. المصدر تحت src/GTPanel، والحزم تحت dist. لا يحتاج البناء اتصالاً بالرسيفر. لإنشاء أمثلة جديدة شغّل tools/make_demo.py ثم حدّث روابطها والتوافق وأعد نشر الأرشيفات والكتالوج معاً.

اختبار قبول الرسيفر: فتح البلجن، رفض عنصر غير متوافق، انقطاع الإنترنت، إلغاء التأكيدين دون تغيير ملفات الهدف، تثبيت مثال نصي، ثم استرجاعه بالزر الأزرق. اختبر ذلك على نسخة USB تجريبية. لا تعتمد البناء للإنتاج قبل نجاح الاختبار على إصدار صورتك المحدد.

المراجع التقنية: https://github.com/opendreambox/enigma2-plugins و https://github.com/opendreambox/opendreambox . هذه مصادر إطار النظام؛ لا تثبت توافق الصورة المعدلة تلقائياً.

## ربط الإصدار 1.0.1

المستودع الافتراضي المضمن هو https://github.com/3bdlios/gt-panel والكتالوج من فرع main في manifest.json. لا يحتاج repository.json خارجي إلا إذا أردت تجاوز الربط الافتراضي؛ إن وجد ملف قديم في /etc/gt-panel/repository.json فهو يأخذ الأولوية، فحدّثه بالقيم الموجودة في repository/repository.json.example. لم يمكن التحقق من توفر المستودع والكتالوج عبر الشبكة أثناء البناء. عند تغيير الكتالوج حافظ على تطابق manifest.json في الجذر مع repository/manifest.json، وأبقِ روابط الأرشيفات مطابقة لملفات repository. لا يزال device.json المحلي وتعريف التوافق الدقيق مطلوبين قبل تثبيت أي عنصر.
